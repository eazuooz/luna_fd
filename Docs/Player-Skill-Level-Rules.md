# 플레이어 스킬 레벨 복구 규칙

원본 `SkillData.skillLevelDiscription` 14개에는 모두 LV 5·10·15·20의 효과가 적혀 있다. 아래는 승인된 복구 판정이며 새 승급 능력을 추가하지 않는다. 네이티브 SkillBalance CSV 32행의 기본 수치는 변경하지 않는다. 저장된 레벨을 읽은 typed 플레이어 생성 요청이 유효 수치와 정책을 불변 `PlayerSkillSnapshot`으로 캡처한다.

`t`는 달성한 네 문구의 수(0~4)다. 같은 10% 증가는 기본값에 누적해 ×(1+0.1t)로 계산한다. LV21 이상에 새 효과를 추정하지 않는다.

| 스킬 | 원문 성장 약속 / 각 LV5·10·15·20 | 복구 규칙 |
| --- | --- | --- |
| FireBall | 데미지·사정거리 10% 증가 | CSV 피해·거리 ×(1+0.1t) |
| Blizzard | 스턴시간 0.5초 증가 | 기본 스턴+0.5t초 |
| Healing | HP회복량 10% 증가 | CSV 회복량 ×(1+0.1t) |
| Thunder | 스킬 범위 10% 증가 | CSV 반경 ×(1+0.1t), 피해는 유지 |
| GoldyBlessing | 골드획득량 3% 증가 | 기존 실제 기본 수입 +18%를 유지하고 +3t%p. 이전 코드의 증가량은 골드 업그레이드 계수와 중복 계산되어 매번 +9%p였음 |
| LoneBleesing | 방어력 5% 추가 증가 | 기존 방어 계수 +1에 +0.05t, 만료 시 같은 값 반환 |
| WaterDropBarrier | 받는 데미지 10% 추가 감소 | 기존 피해 감소 50%에 +10t%p, 최종90% |
| Dwarf | HP 10% 증가 | 소환 HP ×(1+0.1t). 기본 설명의 공격 집중은 기존 DwarfAI.Provoke 반경2를 typed 요청에 설정하며 같은 라운드만 도발 |
| AngerArmy | 광폭화 스탯 10% 추가 | 기존 공격속도 +50%p·이동속도 +100%p 각각 +10t%p. 공격력·방어력 등 새 광폭화 스탯은 만들지 않음 |
| DemiGod | 분신 5초 증가 | 기존 두 분신을 5+5t초 유지. 기존 기간 공식은 이미 동작했음 |
| SerenBlessing | 저항 5% 추가 증가 | 기존 일반 공격·공격 스킬·상태 이상 회피 세 채널 +25%p 각각 +5t%p, 10초 뒤 반환 |
| BeleifWave | 공격력 증가 3% 추가 | 기존 공격 계수 +15%p에 +3t%p, 5초 뒤 반환 |
| KingSlime | 스탯 10% 증가 | 소환 HP·공격력·방어력 ×(1+0.1t). 이동·공격 속도·충전시간은 바꾸지 않음 |
| SkeletonArcher | 스탯 10% 증가 | 소환 HP·공격력·방어력 ×(1+0.1t) |

Seren의 기존 기본 설명은 “모든 저항에 25% 감소”였지만 성장 설명은 저항 증가이고, 실제 기존 구현은 세 회피 채널에 +25였다. 스킬 피해 감소라고 명시한 문구는 없다. 기존 동작을 유지하며 기본 표시 문구를 “파티원 전체의 공격·스킬·상태 이상 회피 확률을 10초간25%증가”로 명확히 한다. `SkillResistance` 피해 배율 감소로 임의 변경하지 않는다.

DemiGod의 기존 유령 데이터 공격력은0이어서 ×1.5만으로는 피해가 없었다. 실제 시전 시점 플레이어 공격력을 typed 소환 요청에 캡처하고 기존1.5배를 적용한다. 플레이어에게 적용된 동일 컨트롤러의 SkullSword 공격 계수는 복사 전에 나누며, 분신이 일반 파티 장비 효과를 한 번 받는다. 다른 시점의 버프는 캡처된 공격력에 포함된다. 유령의 HP·방어·역할·시각 자산은 그대로 사용하고 SO 원본은 수정하지 않는다.

## 검증 범위

- 별도 스냅샷 계약:14스킬 각각 LV4/5,9/10,14/15,19/20 경계와 authored 상한. 기본 CSV·SO·런타임 기본 수치 불변, 요청 뒤 레벨/원본 변경과 분리.
- 기존 기본 레벨14스킬은 실제 UI→컨트롤러→피해/버프/소환 결과 검사에 포함된다.
- 추가 `skill-levels`는14스킬의 실제 LV20 결과를 검사한다. 피해·회복·범위·스턴·골드·계수·피해감소·소환능력치·도발·수명·만료 복원을 측정한다. DemiGod은 SkullSword 장착 상태에서 실제 네이티브 공격의 피해와 한 번만 적용된 장비 계수를 확인한다.
- 이 문서는 기대값 명세다. 실제 통과 여부는 `Logs/NativeRewrite`의 해당 실행 JSON과 전체 프로세스 로그로 판정하며, 작성만으로 통과 표시하지 않는다.
