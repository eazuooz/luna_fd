# 영웅 전투 규칙과 네이티브 전환 검증 범위

이 문서는 현재 `codex/native-framework-hero-repair` 작업의 구현 규칙을 기록한다. 이전 문서에 남아 있던 “미구현” 목록을 그대로 현재 상태로 취급하지 않는다. 사용자는 원본 설명으로 확정할 수 있는 효과를 복구하고, 모호한 부분은 일관된 규칙을 정해서 완성하도록 승인했다. 아래 구현은 새 네이티브 구조에서 재검증하는 중이다. 이전 호환 구조의 테스트 통과를 새 구조의 통과로 인용하지 않는다.

## 데이터와 실행의 기준

- 숫자·enum의 런타임 기준은 GameFramework DataTable의 `Resources/DataTables/UnitBalance.csv`다. 스킬별 프리팹 파라미터는 `EntityParameters.csv`에 두고, 이미지·Spine·프리팹·음원 참조는 순수 `UnitView` 바인딩에 둔다.
- 매 소환의 등급·레벨·진영·대상 ID·소유자 ID·지속 시간·소환 보너스는 `UnitData`/`HeroData`에 먼저 작성한다. `LunaSpawn.Show` 성공 이후에 초기 필수값을 덮어쓰지 않는다. 원본 SO와 공유 프리팹의 스탯은 전투 중 변경하지 않는다.
- 실제 행위자는 `UnitLogic : EntityLogicBase`, 각 영웅은 그 하위 클래스다. 네이티브 Entity 콜백과 해당 행위자가 소유한 `Fsm<UnitLogic>`이 전투를 실행한다. 과거의 `Status`·`UnitAI`·`HeroSkillControl` MonoBehaviour를 검색해 호출하던 중계 루프는 사용하지 않는다.
- 새 스탯과 승급 효과는 `OnShow`에서 동기적으로 완성한 뒤 FSM을 만든다. 과거 Joe의 이전 등급 플래그가 한 프레임 먼저 실행되던 재사용 문제는 지연 초기화를 제거하는 구조로 방지한다.
- 라운드 ID는 실제 피해·파티 오라·소환 골드 수입·플레이어 이동 오라의 적용 범위다. 서로 다른 라운드의 살아 있는 유닛을 같은 좌표에 놓아도 영향을 주면 안 된다. 공격자의 데이터가 존재하면 수신자와 라운드가 일치해야 하며, 출혈·중독의 자기 피해와 명시적인 무소유자 피해 경로는 유지한다. 파티 효과 원본 레지스트리는 도메인 재로딩을 끈 실행에서도 초기화한다.
- 파티 효과는 `Has<T>(rank, roundId)`, `DamageReductionForRound`, `GoldBonusForRound`로 조회한다. 사용되지 않던 `Defined.SkillTrigger_*` 전역 필드와 영웅·라운드의 대입, 전역 피해 감소·골드 속성은 삭제했다. 모든 유닛이 매 프레임 전역 플래그를 다시 계산하던 경로도 제거했다. 유닛별 보너스 적용·복원 상태는 유지하며, `Refresh`는 남은 무효 참조를 정리하는 용도로만 사용한다.
- STAR2는 STAR1, STAR4는 STAR3 효과를 상속한다. 설명이 빈 승급에 임의의 추가 피해나 확률을 만들지 않고 아래에 명시한 기존 효과를 유지한다.

## 모호했던 항목에 대한 결정

- CSV에 복사된 옛 임시 Stamina와 화면 설명의 명시적인 간격이 달랐던 14영웅은 화면에 명시된 간격으로 수정했다. 별도 간격이 없는 Alice·Elena·Pochi·Goldy 및 설명이 빈 Pobi·Lennon·Tira는 기존 숫자를 유지한다.
- “200% 증가”는 기존 값의 3배, “300% 증가”는 4배로 처리한다. 기존 실제 기본 공격 배율은 유지한다. 예컨대 Scarlet의 기본 40배 피해를 다른 임의의 값으로 재설계하지 않는다.
- Miu의 “저주 10 감소”는 저주 강도 10%p 정화로 정했다. 저주는 방어·이동 속도를 20%p 낮추며 최대 80%p까지 누적한다. 정화는 현재 강도에서 빼고 정확히 재계산한다.
- Matilda의 미니·불 마틴은 기존 `miniMartinEnemy` 정의의 체력 150을 사용하는 실제 피격 가능 유닛으로 바꾸고 소환 진영은 명시적으로 아군으로 설정한다. ULT1부터 영구 무적이며, 소환 인스턴스의 수명은 30초로 제한한다. 이전처럼 전 등급에서 피격 불가능한 시각 효과를 만든 뒤 “무적”이라고만 표시하지 않는다.
- Pobi/Lennon의 “속도 30 감소?” 주석은 미확정 아이디어로 보고 새 감속 효과를 만들지 않았다. 계산되어 있던 3/4 소환 수를 실제 소환 수에 적용한다. Tira STAR3·ULT2, Pobi/Lennon/Dren ULT2, Pochi ULT1·ULT2에는 알려진 별도 승급 효과가 없어 이전 등급 효과를 상속한다. 이 항목은 새 고유 능력을 복원했다는 뜻이 아니다. 현재 UI 설명은 이 상속 동작을 명시하며, 원래 의도한 고유 능력·새 수치의 설계는 이번 복구 범위에 추가하지 않았다.
- Raccon의 기본 회전은 기존처럼 지상·공중 적 비타워를 공격한다. 공중 전용 추가 피해만 분리한다. 회전 중 재진입을 막고, 타깃이 사라져도 월드의 두 타워 사이를 벗어나지 않으며, 완료·사망·숨김에서 이동·슈퍼아머·FSM의 진행 플래그를 해제한다. 뷰포트 끝으로 전투 좌표를 잘라 내지 않는다.
- 소환수 11종·DragonPet·일반 해골 마법사·옛 보스 5종의 잘못된 enum 값과 Dekoo의 아군 진영을 교정했다. 보스 전용 피해 보정은 `Boss`와 `TowerAndBoss` 모두에 적용한다. 숫자 능력치까지 일괄 바꾸지는 않는다.
- 파티 오라는 같은 라운드에서 살아 있는 같은 종류의 마지막 영웅이 사라질 때 해제한다. 시각 효과·상태 보너스는 중복으로 쌓지 않으며 적용한 수치만 되돌린다. 병사/영웅 구분과 공격형 분류는 CSV에서 관리한다.

수정된 CSV 행과 이전 값은 `Logs/NativeRewrite/balance-rule-corrections.json`에 기록한다.

## 전투 종료·보상·배경의 복구 규칙

- 과거 `MonsterDropItem` 호출은 타워 사망 분기에만 들어 있었다. 일반 스테이지의 실제 적 유닛 사망 완료에서 네이티브 `UnitDiedEventArgs`를 한 번 발행하고, 해당 라운드가 적·비타워·현재 진행 중 조건을 확인한 뒤 원래 Monster 보상 표를 한 번 추첨하도록 고쳤다. 아군·미리보기·다른 라운드·단순 숨김·소환 수명 종료에는 사망 보상을 만들지 않는다.
- 보상은 라운드가 소유한 지급 대장에 기록한다. 시각적 아이템을 주울 때 한 번 지급하고, 결과 화면 또는 라운드 종료 때 미수령분을 정산한다. 승리 직후 재시작·로비 이동으로 비동기 드롭이나 자석 이동이 끝나지 않아도 보상이 사라지거나 뒤늦게 중복 지급되지 않아야 한다.
- 사망·폭발·지면 광역 효과는 시전자 퇴장 이후에도 원래 애니메이션을 마칠 수 있지만 해당 라운드가 끝나면 함께 정리된다. 좌표만 받던 생성 호출에 라운드 ID가 빠져 0번 라운드에 남을 수 있던 경로를 수정했고, 실제 Entity 생성 이벤트에서 무소유·라운드 0 효과가 새로 생기는지 검사한다.
- 일반 스테이지는 살아 있는 아군 타워가 있을 때만 플레이어를 재생성한다. 아군 타워가 없는 보스·무한 던전은 플레이어의 실제 사망 완료로 패배한다. 현재 무한던전의 완료 층, 최고 기록과 정예 보상은 별도의 레벨 디자인 규칙을 따른다. [레벨 디자인과 검수](Level-Design-QA.md)
- 배경은 `LunaStageBackdropLogic`이 명시적인 스크롤 판·배경 악마·효과 방출기 바인딩을 소유한다. 로비 역시 같은 네이티브 생성 경로를 사용한다. 문은 원본 위치와 음원을 유지하며, 기존 프레임당 0.02 이동을 초당 1.2로 바꿔 프레임 속도에 무관하게 열린다. 반복 열기 요청은 중복 실행하지 않고 재사용 시 닫힌 위치로 복원한다.
- 실제 Basic 스킨의 공격 직후 사망 검사에서, Spine의 이전 공격 트랙 완료가 새 사망 트랙을 idle로 덮어 사망 이벤트와 퇴장이 영원히 발생하지 않는 문제가 확인됐다. 진단의 `Before death: attack` → `After BeginDeath: death` → `Complete=attack, sameTrack=False, FSM=PlayerDeathState, HP=0` 기록은 `Logs/NativeRewrite/skins-basic-diagnostic-runtime02.json`에 보존했다. 공통 이벤트·완료 콜백이 현재 트랙 0의 동일한 `TrackEntry`만 처리하도록 수정했다. 플레이어 재정의도 이 공통 진입점을 통과하므로 같은 수정이 적용된다. 조건을 완화하지 않은 7개 스킨의 공격·사망·새 생명 생성 검사는 이후 `all-runtime01.json`에서 모두 통과했다. 전체 보고서 자체는 뒤의 별도 Thunder 검사에서 중단됐으므로 전체 통과로 취급하지 않는다.

`Logs/NativeRewrite/all-runtime01.json`은 169개 검사 뒤 Thunder 검사에서 중단됐다. 이때 테스트가 스테이지 초기화의 배속 변경을 반영하지 못한 기대값을 사용하던 부분을 수정했다. `all-runtime02.json`은 4개 검사 뒤 요청 스냅샷 fixture가 전투 컨트롤러를 만들지 않는 Preview 모드를 사용해 중단됐고, 해당 fixture를 Staged로 수정했다.

**`Logs/NativeRewrite/all-runtime03.json`은 311개 검사를 통과한 뒤 `SkeletonMagicianLeader`의 두 번째 스킬 요청 검사에서 중단됐다.** 통과한 범위는 영웅 237개, 이동 1개, 상태·파티 격리 2개, 스킨 7개, 플레이어 스킬 14개, 일반 행위자 45개, 부팅·소유권 5개다. 해골 마법사 리더는 공격 범위가 0이고 일반 공격 애니메이션이 없으므로 첫 피해가 자연 충전된 스킬의 이벤트에서 발생한다. 테스트가 그 트랙이 끝나기 전에 다시 스킬을 요청해 실제 중복 방지에 걸리는 원인을 확인했다. 현재 트랙 완료를 기다린 후 별도 요청의 실제 피해를 검증하도록 fixture를 수정했으며, 스킬의 성공 조건이나 중복 방지는 완화하지 않았다. 해당 스킬의 같은 라운드 대상 조건도 추가했다. 감사와 행위자 검사를 재실행 중이며, 아직 실행되지 않은 뒤쪽 사례를 통과로 계산하지 않는다.

장주기 검사는 발동 등급 미만의 음성 사례, 살아 있는 같은 소환수의 중복 제한, 실제 수명 종료와 새 ID 재소환, 시전자 사망·숨김 후 정리, 원본 바인딩·정의의 불변성도 검사한다. 아래 추가 항목 역시 최종 새 실행 보고서로 판정한다.

1. 22영웅 × 7등급의 실제 피해·회복·확률 효과·소환 수·파티 효과. 오류가 없다는 것만으로 능력 발동 성공으로 처리하지 않는다.
2. 긴 지속 시간(왕 60초, 마틴 16초), 사망 중 지연 공격 취소, 비동기 로딩 중 소환 취소, 소환자 사망 시 자식 제거, 등급을 바꾸어 재사용했을 때 계수·콜백·변신 복원.
3. 회전 중 반복 입력·타깃 사망·양쪽 타워 경계·군중 충돌·넉백 종료의 유한한 월드 좌표.
4. 공중 분류는 부유 정령·펫이라는 명시적 역할을 기준으로 `Pobi_ghost`, `Luna_ghost`, `Sword_Sprit`, `DragonPet` 네 행에 설정했다. 날개만 있는 지상 유닛과 지면의 RedDragon 보스는 포함하지 않는다. 해당 네 자산의 실제 부유 자세와 공중 전용 추가 피해·감소를 실행 검증하고, 분류 필드가 존재한다는 것만으로 효과 성공을 판정하지 않는다. 이 네 원본 자산은 기본적으로 아군이므로 적 공중 판정 테스트는 같은 자산의 소환 Data.Side를 적으로 설정한 격리 사례로 확인한다.
5. 새 네이티브 생성·숨김·실패·취소마다 데이터 참조가 정확히 한 번 반환되고, 미리보기·대기 중 웨이브는 공격·치유 대상이나 주기 스킬 실행자로 참여하지 않는지 확인한다.

이전 `matrix-joe-prefixed-11` 등의 보고서는 삭제하지 않되 호환 구조에서 발견했던 문제의 역사적 증거로만 사용한다. 이번 네이티브 구조의 최종 검증 보고서가 준비되기 전까지 전체 전환이나 모든 영웅 검수가 완료되었다고 표시하지 않는다.
